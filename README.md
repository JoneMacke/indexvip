# indexvip · AI API 落地页

一套原创的 AI API 服务主页，设计语言参考现代 SaaS 落地页，但品牌、文案、组件和视觉表现均为重新设计。

## 本地预览

```powershell
npm run dev
```

然后访问 `http://127.0.0.1:4173`。

## 构建

```powershell
npm run build
```

构建结果位于 `dist` 文件夹，可直接部署到任意静态网站平台。

## 已实现

- 桌面端、平板和手机响应式布局
- 浅色 / 深色主题切换与本地记忆
- 动态运行时间
- API 网关流转视觉图
- 模型生态、核心能力、接入流程、价格、FAQ 和行动号召区域
- 滚动进入动画
- FAQ 折叠交互
- 代码一键复制
- 无框架、无运行时依赖

## 快速定制

- 品牌和页面文案：`index.html`
- 颜色、间距和组件样式：`styles.css` 顶部的 CSS 变量
- 运行时间与交互：`script.js`
- 邮箱、登录和注册链接目前是演示内容，上线前请替换成真实地址
